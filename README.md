# JS Core Practice

Practice implementations while learning JavaScript fundamentals
through Hitesh Choudhary's Web Dev course. Each folder is a
self-contained concept or mini-project.

## Topics covered

- DOM/BOM manipulation
- LocalStorage persistence
- Async JS, Promises, Closures
- OOP in JavaScript (prototypes, classes)
- CRUD operations
- API handling

## Structure

Each numbered folder = one concept/project, runnable independently.
